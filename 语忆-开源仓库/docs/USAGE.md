## 0. 先搞清楚你在哪个环境

同一个 `index.html`，在三种环境里能力**不一样**。遇到「怎么没反应」先对照这张表：

| 能力 | `file://` 双击打开 | `http://127.0.0.1:8790/` | `https://<局域网IP>:8444/` | **APK** |
|---|---|---|---|---|
| 看界面 / 点按钮 | ✅ | ✅ | ✅ | ✅ |
| 安全上下文 | ❌（origin 是 `null`） | ✅ | ✅ | ✅ |
| 麦克风录音 | ❌ | ✅ | ✅ | ✅ |
| 振动 | ❌ | ✅ | ✅ | ✅ |
| 系统通知 | ❌（SW 注册被拒） | ✅ | ✅ | ✅ |
| 语音播报（TTS） | 依赖浏览器 | 依赖浏览器 | 依赖浏览器 | ✅ **原生 TextToSpeech** |
| 离线识别（Vosk WASM） | ❌ | ✅ | ✅ | ✅ |
| 导出文件落到「下载」 | 浏览器下载 | 浏览器下载 | 浏览器下载 | ✅ **写手机 Download 目录** |

**一句话**：`file://` 只能看界面；要真机体验走服务；要完整体验（离线识别 + 原生 TTS + 真落盘）装 APK。

## 1. 起来：三种启动方式

### 方式 A：一键脚本（推荐）

```powershell
# 仓库根目录下双击，或在 PowerShell 里：
.\手机预览.bat
```

它会：检查 `python` → 提示手机连同一个 WiFi → 运行 `python _tools\serve-mobile.py`。

脚本会打印两类地址：

```
http://127.0.0.1:8790/          ← 电脑上用；手机 USB 直连也用这个
https://<电脑局域网IP>:8444/     ← 手机连 WiFi 用这个（会打印实际 IP）
```

**为什么两个端口差一个 `s`**（值得理解，不是随便定的）：

- 浏览器只在「**安全上下文**」里给麦克风、振动、通知、Service Worker。
- `http://127.0.0.1` 和 `http://localhost` 被标准**算作**安全上下文 —— 所以电脑上走 http 完全够用，
  还省掉自签证书那个「不安全」提示。
- 但手机访问电脑时地址是 `https://<局域网IP>`，既不是 localhost 也不是 127.0.0.1，
  **必须 HTTPS** 才算安全上下文 → 所以 8444 用自签证书。
- 证书由 `serve-mobile.py` **现场生成**（`cryptography`），SAN 里写入当前局域网 IP，
  存在 `_tools/.cert/`。**该目录不进仓库**，删掉也不影响：下次启动会重新签。
  换网络（IP 变了）时会自动重签。
- 首次需要：`pip install cryptography`。没装脚本会明确提示。

### 方式 B：手机 USB 直连（不想连 WiFi / WiFi 是隔离的）

```powershell
# 先起服务（方式 A），再：
.\手机USB直连.bat
```

它做的事：轮询 `adb devices` → 检测到手机就 `adb reverse tcp:8790` 与 `tcp:8444` →
用 `am start` 打开 `http://127.0.0.1:8790/`。拔掉再插上会自动重建。

好处：手机上访问的是 **`127.0.0.1`**，所以**走 http 也算安全上下文**，
振动/通知都能用，而且**没有**自签名证书的「不安全」提示。

注意：它**只**映射本项目的 8790 / 8444，**不会**执行 `adb reverse --remove-all`（不动你别的项目）。

### 方式 C：只起服务，手动开

```powershell
python _tools/serve-mobile.py                 # 默认 http 8790 + https 8444
python _tools/serve-mobile.py --http 9000 --https 9443   # 换端口
```

服务器**只放行白名单路径**（不给目录列表，`_shots/`、`design/`、`.git` 都拿不到）：

| 路径 | 用途 |
|---|---|
| `/`、`/index.html` | 产品本体 |
| `/sw.js` | Service Worker（通知必须走它） |
| `/lib/docx-mini.js`、`/lib/braille-zh.js`、`/data/braille-zh.json` | 导出用的三个资源 |
| `/data/asr/manifest.json`、`/data/asr/yuyi-asr.js`、`/data/asr/vosk.js`、`/data/asr/model.tar.gz` | 离线识别资产（全本地，不走 CDN） |
| `/diag`、`/diag.html` | 麦克风/识别诊断页 |
| `/aitest`、`/aitest.html` | AI Key 实测页（同源，能读到手机已存配置；**不显示完整 Key**） |
| `/README-预览说明.md` | 开发期记录 |

## 2. 逐功能操作步骤

### 2.1 录音与三类结束方式

1. **开始**：点中间大圆「开始录音」，或说「小语，开始录音」。
   播报会说「好的，开始录音。录音结束时请说『小语，结束』。」
2. **录音中**：卡片上有计时器；可说「小语，暂停」？——**不行，见下方说明**。
3. **暂停 / 继续**：**只有按钮**（录音卡片上）。
   语音侧**刻意移除**了「暂停录音 / 继续录音 / 语速调节」，因为课堂噪声下它们与「结束」极易互相误判。
4. **结束并保存**：说「**小语，结束**」，或点「结束录音」。
   然后进入[二次确认](#22-小语结束的三步确认)，确认后原音频保存到本机。

**「原声优先」原则**：按下录音就开始存原始音频。**先保存音频，再决定要不要转写。**
所以 AI 总结失败、转写失败、断网、导出失败 —— 都**不会**弄丢你的录音。
原音频在「笔记 → 原音频」里，可播放 / 下载 / 重命名 / 删除。

### 2.2 「小语，结束」的三步确认

```
① 必须说完整唤醒词              ② 小语出声反问（弹窗同时出现）        ③ 说「是」
   「小语，结束」                  「要结束录音吗？                     → 真的结束并保存
   ❌ 只说「结束」→ 不认            已录 00:21。结束后会保存这段原音频。
                                    说『是』结束并保存；说『不用』继续录。」
```

- 弹窗三个按钮：**结束录音** / **继续录** / **取消**。
- 说「**不用**」/「继续录」→ 录音不中断，继续录。
- 说「**取消**」→ 关掉弹窗，仍在录音中。
- 已录时长会念出来（例：`已录 00:21`），用来确认这段没白录。
- 为什么这么啰嗦：见 [README §4.2 课堂防误停](../README.md#42-结束录音小语结束三步确认课堂防误停)。

### 2.3 四步引导（录音结束之后）

| 步 | 小语的提问 | 可以说什么 | 效果 |
|---|---|---|---|
| ① | 这段原音频归到哪个类目？ | 类目名 /「跳过」 | 建类目或跳过 |
| ② | 要不要做 AI 笔记总结？ | 「要」/「不用」 | 要 → 离线转写 + 大模型提炼 |
| ③ | 这条 AI 笔记归到哪个类目？ | 类目名 /「同上」/「跳过」 | 给笔记打标签 |
| ④ | 要不要导出？ | 「要」（默认中文盲文 Word）/「中文文档」/「盲文」/「不用」 | 直接导出 |

每一步都可以说「**重复**」重念当前这问；说「**返回**」/按 `Esc` 回上一步。
每一步也都有按钮，不强制语音。

### 2.4 建类目（自己起名 → 复述 → 说「对」）

```
你说  「高等数学」            ← 自由文本，长名字也认
小语  「新建类目：高等数学。对吗？」
你说  「对」                  → 建好并归入
你说  「重说」/「再说一遍」     → 小语重新问一次
```

名字的解析规则：剥掉唤醒词和「归到…」「新建…」这类引导词，**其余原样保留**。
所以「第3章 导数与微分」「英语听力 Unit 5」这类都能用。

### 2.5 待办与提醒（语音 5 步 + 三条提醒通道 + 两个出口）

入口：说「**小语，待办事项提醒**」，或点「新建待办」，或在待办面板点「新建」。

| 步 | 小语 | 你说 |
|---|---|---|
| 1 | 请口述录入待办事项内容，说完后说**完成录入**。 | 说内容 → 「完成录入」 |
| 2 | 已识别待办事项，请问**内容是否正确**？ | 「对」/「不对」 |
| 3 | 请问**设置提醒时间**？ | 「明天早上八点」「10 分钟后」 |
| 4 | **提醒方式**选择闹钟响铃，还是震动？ | 「震动」/「铃声」 |
| 5 | 请**确认保存**。 | 「是」 |

到点提醒三条通道同时/接力：**三段式振动 → 系统通知 → 语音播报（慢速重复 2 遍）**。
两个出口：

- 「**小语，知道了**」/「明白了」/「停」→ 停止振动与播报，并标记为已提醒。
- 「**小语，延后十分钟**」→ 停当前提醒，10 分钟后按相同规则重新触发。

语音指令**优先于触摸，且不等播报读完**。

**验证马达是否好用**：
- 待办面板 →「**试一次三段式振动节奏**」按钮，或说「**试听**」。
- 它会**同时震动两下并出声**（刻意如此）。于是：
  - **有振动、没声音** → 媒体音量问题（调媒体音量，不是铃声音量）。
  - **有声音、没振动** → 马达/权限问题，或系统关了触感反馈。
  - **两者都没有** → 先点一下页面（浏览器要求首次交互后才允许振动），再试。

### 2.6 四句「不会迷路」的标准指令

| 说 | 效果 |
|---|---|
| 「**我在哪**」 | 报出当前页面/面板，以及在不在录音 |
| 「**下一条**」 | 列表里往下一条，并念出内容 |
| 「**上一条**」 | 回上一条 |
| 「**重试**」 | 重来一次刚才失败的操作/识别 |
| 「**报告问题**」 | 把当前状态、所在页面、最近错误**全部念出来**（盲人无法截屏 → 这是远程求助唯一通道） |

### 2.7 「重复」与「试听」

- 「**重复**」= 重念**当前这条提问**（`lastAsk`）；没有当前提问时才退回上一条提示。
  换页会立刻解除提问保护，所以不会念串。
- 「**试听**」= 振动+声音的**联合自检**（见 2.5），**不是**播放录音。
  播放录音用「原音频」面板里每条的「播放」。

### 2.8 导出（三种格式）

| 说什么 | 格式 | 扩展名 |
|---|---|---|
| 「要」/「中文盲文 Word」 | 中文盲文 Word（**默认**） | `.docx` |
| 「盲文」/「BRF」 | 盲文 BRF | `.brf` |
| 「中文文档」/「中文 Word」 | 中文 Word | `.docx` |

- 导出对象是**这条 AI 总结笔记**（弹窗里有长念版说明三种格式）。
- **APK**：文件写到手机**「下载」/ Download**（API 29+ 走 MediaStore 无需权限；≤28 要存储权限）。
  「导出记录」面板里可以重新下载或删除。
- **浏览器**：走浏览器自己的下载机制，落到浏览器「下载」。
- **导出没反应**：先看是不是已经在浏览器下载栏里了（见排错表）。

### 2.9 AI Key 怎么填（总结 / 转写两套）

「我的 → AI 接口配置」：

1. 选**服务商**（18 个预设，选中后接口地址与常用模型自动填好）。
2. 点「**粘贴**」把 Key 贴进来（省去在手机上敲长串）。
3. 点「**保存配置**」；或先点「**测试连接**」发一次真请求看 HTTP 状态。

- 「**总结**」与「**转写**」**分开配**，可用不同服务商。
- 带「有转写」标记的才有转写接口：硅基流动 / OpenAI / OpenRouter / Groq / Together。
- Key **只写在本机 `localStorage`**，不上传任何服务器；页面里输入框默认是 `password` 类型，
  点「显示」才明文（**用完记得点回去**）。
- 「测试连接」被 **CORS** 拦时会明说是**服务商策略，不是 Key 错**。
- **转写在本机离线完成，不上传**；只有生成总结时才联网。

## 3. 只有语音怎么操作（盲人视角的完整走法）

这一节假设**你完全看不到屏幕**，只靠耳朵和手指。整条链路如下（每一步都有播报）：

```
① 打开语忆
   → 播报/读屏报出当前是首页
② 点一下页面（或按任意键）
   → 浏览器要求首次交互后才允许振动与声音
③ 说「小语，开始录音」   （或摸到中间大圆点一下）
   → 听到「好的，开始录音。录音结束时请说『小语，结束』。」
④ 上课，正常听讲（录音中）
⑤ 说「小语，结束」
   → 听到「要结束录音吗？已录 XX:XX。说『是』结束并保存；说『不用』继续录。」
⑥ 说「是」
   → 原音频保存；进入四步引导
⑦ 「这段原音频归到哪个类目？」 → 说「高等数学」
   → 「新建类目：高等数学。对吗？」 → 说「对」
⑧ 「要不要做 AI 笔记总结？」 → 说「要」
   → 离线转写（**可能慢于实时，RTF 1.4–2.0**，见 README §6.2）
⑨ 「这条 AI 笔记归到哪个类目？」 → 说「同上」
⑩ 「要不要导出？」 → 说「要」（= 中文盲文 Word）
   → 文件落到手机「下载」
```

**任何时候不知道自己在哪：说「我在哪」。**
**任何时候没听清：说「重复」。**
**任何时候卡住要求助：说「报告问题」，然后把手机递给别人。**

### 只靠语音能做的 / 不能做的（当前版本事实）

| ✅ 能 | ❌ 不能（必须用手） |
|---|---|
| 开始录音、结束录音（带确认） | 暂停录音、继续录音 |
| 四步引导的每一问 | 调节朗读语速（按钮/设置在「我的」里） |
| 建类目、归类 | 自由闲聊（**刻意不支持**，低置信只提示重说） |
| 待办 5 步录入、确认、延后 | 拖动排序、长按重命名 |
| 我在哪 / 下一条 / 上一条 / 重试 / 报告问题 | 在弹窗里逐字编辑文本 |
| 重复 / 试听 / 帮助 / 退出 / 返回 / 取消 | |
| 打开笔记、原音频、待办、目录、导出记录 | |
| 导出三种格式 | |

> 「自由闲聊」不支持是**设计选择**，不是缺陷：开放域对话会让指令误触发率飙升，
> 而误触发的代价是「一整节课的录音被半句话结束」。

## 4. 排错表

| 症状 | 最可能的原因 | 怎么查 / 怎么修 |
|---|---|---|
| **完全没声音** | ① 媒体音量为 0（不是铃声音量）② 手机没有中文 TTS 引擎 ③ 没先点一下页面 | ① 放首歌确认媒体音量 ② 说「试听」：**有振动没声音 = 音量**；**都没 = 引擎** ③ 装 APK 后打开内置自检，看 `YuyiNative.speak` 是不是「有」；不是就装 TTS 引擎（见 BUILD.md） |
| **说了没反应** | ① 语音开关没开 ② 识别引擎没起来 ③ 云端识别通道不通（目标机型实测固定 `aborted`） | ① 看/听药丸状态：灰「点这里开启语音唤醒」= 没开，点它 ② 药丸显示「上次识别出错 · 点这里重试」就点它 ③ 说「**报告问题**」把状态念出来；或用 `/diag` 看识别引擎状态。**APK / 离线识别不依赖云端，优先用 APK** |
| **只说「结束」没反应** | **这是故意的** | 「结束」必须带唤醒词：「**小语，结束**」（课堂防误停，见 README §4.2） |
| **说了「小语，结束」但还在录** | 进入了二次确认，在等你答「是」 | 说「**是**」结束并保存；说「**不用**」继续录 |
| **录音中说话被录进去了** | 正常 | 语音指令与录音内容**相互隔离**，但麦克风是同一个；指令本身会被录进原音频 |
| **导出没反应** | ① 浏览器下走的是浏览器下载 ② 浏览器里没有原生保存桥 ③ 弹窗还等你确认 | ① 看浏览器下载栏/通知栏 ② **APK 才支持原生保存到「下载」** ③ 确认已选格式并点/说确认 |
| **导出文件找不到** | 路径不同 | APK → 手机**「下载」/ Download** 目录（也在「导出记录」面板）；浏览器 → 浏览器「下载」 |
| **模型加载很慢 / 首次卡住** | 首次要下 **41.9 MB** 的 `model.tar.gz` 并解包（解包后约 65 MB） | 首次耐心等；之后 `vosk-browser` 把结果存进 **IndexedDB**，第二次会跳过。若一直失败，确认 `data/asr/vosk.js` 与 `data/asr/model.tar.gz` 在（仓库里**不含**这两个文件，需 `python _tools/fetch-asr-wasm.py`） |
| **转写很慢（比录音还久）** | 正常 | 小模型 + 手机 CPU，**RTF ≈ 1.4–2.0**：10 分钟录音要等 14–20 分钟。见 README §6.2 |
| **转写错字多** | 小模型面向短指令 | 长课堂录音精度一般。结果页会如实标注「离线转写，可能有错字」，可用「重新总结」或人工修正 |
| **AI 总结报 HTTP 错误** | ① Key/地址不对 ② 服务商 CORS 策略 | 「测试连接」会打印 HTTP 状态与耗时；提示里会明说「是 CORS 策略，不是 Key 错」 |
| **AI 总结说「未配置」** | 没填 Key | 状态行会明确说「总结：未配置（生成 AI 总结时会先用演示数据，并说明未配置）」→ 去「我的 → AI 接口配置」填 |
| **振动不生效** | ① 先点一下页面 ② 系统关了触感反馈 ③ 浏览器不支持 | 说「试听」自检；APK 里振动更可靠 |
| **通知弹不出来** | `file://` 打开时 SW 注册被拒（origin 为 `null`） | 走 8790 / 8444 服务，或装 APK |
| **手机打开 https 提示「不安全」** | 自签证书的正常表现 | 点「高级」→「继续前往」；或改用 USB 直连走 `http://127.0.0.1:8790/`（无提示） |
| **LAN 地址变了、连不上** | 换了 WiFi/热点，IP 变了 | 重启 `手机预览.bat`：脚本会自动重签带新 IP 的证书并打印新地址 |
| **`pip install cryptography` 失败** | 没网 / 无轮子 | 改用 USB 直连 + `http://127.0.0.1:8790/`（**不需要证书**） |
| **手机上页面白屏** | 用 APK 时 assets 条目名问题（历史 bug） | 已修：构建脚本会规范化条目名并强制 `model.tar.gz`/`resources.arsc` 为 STORED。若自建请勿跳过第 6 步，见 BUILD.md |

## 5. 诊断页怎么用

服务起着的时候，手机/电脑打开 **`/diag`**（麦克风与识别诊断页）。它显示：

- 拾音强度条（**实测参考：安静时约 0.002，正常说话峰值约 0.242**）
- `getUserMedia` 是否成功取流
- 识别引擎状态（**就是在这里看到云端识别固定返回 `aborted`** —— 这是当年「说了没反应」的根因）
- 事件日志

另有 **`/aitest`**：AI Key 实测页。它同源，所以能读到手机里已保存的配置，
用**真实 Key 发真请求**，但**不显示完整 Key**（排查 Key 问题用）。

> 注意：`/diag` 与 `/aitest` 只在预览服务器下存在；装成 APK 后没有这两个页面，
> APK 里对应的是**内置自检页**（见 [BUILD.md](BUILD.md#8-怎么打开内置自检页)）。

## 6. 开发者：验收脚本怎么跑

这些脚本都在 `_tools/`，**不需要 npm install**（PowerShell / Python / Node 直接跑）。

```powershell
# 主闸门：85 项断言，带 exit code；文件必须 UTF-8 with BOM
powershell -ExecutionPolicy Bypass -File _tools\verify-todo-vibration.ps1

# 三个既有探针（UI / 新流程 / 新页面）
powershell -ExecutionPolicy Bypass -File _tools\verify-ui.ps1
powershell -ExecutionPolicy Bypass -File _tools\verify-newflows.ps1
powershell -ExecutionPolicy Bypass -File _tools\verify-newscreens.ps1

# docx 生成器（137 项，ZIP 结构 + OPC 完整性 + python-docx 逐条回读）
python _tools\verify-docx-mini.py

# 中文盲文：与后端 Python 逐字符等价（217 项 + 全表 44,388 条聚合校验和）
python _tools\verify-braille-parity.py

# 容错指令匹配
python _tools\verify-match-cmd.py

# 离线识别（浏览器里跑，可用 --block-external 阻断全部外部域名）
python _tools\verify-asr-offline.py
node   _tools\verify-asr-wasm.mjs

# 安全上下文与能力自检（CDP 真实页面探 isSecureContext/SW/通知/vibrate/wakeLock）
node _tools\check-https-capabilities.mjs --url http://127.0.0.1:8790/
```

- 探针需要 **Chromium headless shell**（随 Playwright 安装），脚本里会自己找。
- 主闸门与探针的**临时文件前缀是 `vtv-`**，会自动清理；若中断可手动删 `%TEMP%\vtv-*`。
- **PowerShell 5.1 的坑**：这些 `.ps1` 文件必须是 **UTF-8 with BOM**，
  否则 PS 5.1 按 ANSI（GBK）解码会直接解析失败。**用工具改这些文件会丢 BOM**，见 [BUILD.md](BUILD.md#7-一个必须知道的坑改脚本会丢-bom)。

验收数字与「未验证清单」见 **[VERIFICATION.md](VERIFICATION.md)**。
